# Anomaly Detection in X-ray Diffraction Images (RefleX)

Multilabel classification of anomalies in macromolecular X-ray diffraction images, using deep learning (PyTorch).
Each image can show several anomalies at once (for example an ice ring together with strong background), so the
task is framed as **7 independent binary decisions per image**.

The project reproduces and evaluates the approach of the reference paper stored in
[materiais/1-s2.0-S0957417421001810-main.pdf](materiais/1-s2.0-S0957417421001810-main.pdf), on the **RefleX** image
dataset, and reports the same metrics used there.

## Anomaly classes

| Class | Test positives |
|---|---|
| `ice_ring` | 46 |
| `diffuse_scattering` | 44 |
| `background_ring` | 389 |
| `non_uniform_detector` | 224 |
| `loop_scattering` | 264 |
| `strong_background` | 300 |
| `artifact` | 126 |

The classes are strongly imbalanced (`ice_ring` and `diffuse_scattering` are rare) and co-occur often; see
`reports/figures/<run>/class_freq.png` and `cooccurrence.png`.

## Approach

- **Model:** ImageNet-pretrained ResNet50 with the final layer replaced by a 7-output linear head
  ([src/model.py](src/model.py)). Outputs are logits; a sigmoid gives one probability per class.
- **Loss:** `BCEWithLogitsLoss` with a per-class `pos_weight` (negatives / positives) to counter class imbalance.
- **Optimizer:** AdamW, with optional separate learning rates for the head and the backbone.
- **Two training stages** (both were run):
  1. **Frozen baseline** – only the new head is trained (`baseline_resnet50_frozen`).
  2. **Fine-tuning** – the whole backbone is unfrozen (`resnet50_finetune`).
- **Input:** images are resized to 512×512 and normalized with ImageNet statistics.
- **Augmentation** ([src/transforms.py](src/transforms.py)):
  - `rotate10` – horizontal/vertical flips, rotation of ±10°, light brightness/contrast jitter.
  - `dihedral` – horizontal flip plus random 90° rotations (the 8 symmetries of the square; no interpolation,
    no black corners), plus the same jitter.
- **Model selection:** the checkpoint with the best validation mean Average Precision (mAP) is kept.
- **Decision thresholds:** one threshold per class, chosen on the **validation** set to maximize F1, then frozen and
  applied to the test set. Nothing is tuned on the test set.
- **Explainability:** Grad-CAM on the last convolutional block ([src/explain.py](src/explain.py)).

## Results

All numbers below are on the held-out **test set** (632 images), with thresholds fixed on the validation set.
The fine-tuned model was evaluated with bfloat16 inference (`--amp`), matching how it was trained.

### Summary (mean over the 7 classes)

| Run | Best val mAP | Test mAP | Test macro F1 | Test MCC (mean) | Exact match ratio |
|---|---|---|---|---|---|
| `baseline_resnet50_frozen` | 0.787 | 0.733 | 0.655 | 0.495 | 0.218 |
| `resnet50_finetune` | 0.912 | **0.911** | **0.850** | **0.781** | **0.566** |

Fine-tuning the whole backbone is a large improvement over training only the head.

### Per-class test results – `resnet50_finetune`

| Class | AP | Precision | Recall | F1 | MCC | AUC |
|---|---|---|---|---|---|---|
| `ice_ring` | 0.913 | 0.815 | 0.957 | 0.880 | 0.873 | 0.995 |
| `diffuse_scattering` | 0.796 | 0.756 | 0.705 | 0.729 | 0.710 | 0.974 |
| `background_ring` | 0.964 | 0.930 | 0.859 | 0.893 | 0.742 | 0.941 |
| `non_uniform_detector` | 0.843 | 0.682 | 0.862 | 0.761 | 0.617 | 0.902 |
| `loop_scattering` | 0.982 | 0.920 | 0.955 | 0.937 | 0.890 | 0.984 |
| `strong_background` | 0.979 | 0.898 | 0.937 | 0.917 | 0.839 | 0.978 |
| `artifact` | 0.903 | 0.863 | 0.802 | 0.831 | 0.792 | 0.956 |

Aggregate metrics: Precision 0.838, Recall 0.868, F1 0.850, F2 0.860, mean MCC 0.781, Jaccard index (samples) 0.794,
exact match ratio 0.566. `diffuse_scattering` and `non_uniform_detector` are the hardest classes.

Figures (PR curves, error-leakage matrix, class frequency, co-occurrence, Grad-CAM) are in
[reports/figures/](reports/figures/), one folder per run. Per-epoch training curves are in
`reports/history_<run>.csv`.

## Setup

Requirements: Python 3.11+, a CUDA GPU is strongly recommended (training runs on CPU but is slow).

```bash
python -m venv .venv --system-site-packages
.venv\Scripts\activate          # Windows  (source .venv/bin/activate on Linux/macOS)
pip install torch torchvision numpy pandas pillow opencv-python-headless tqdm
pip install -r requirements.txt  # torchmetrics, scikit-learn, matplotlib, grad-cam
```

`requirements.txt` lists only the extra packages; `torch`, `torchvision`, `numpy`, `pandas`, `pillow`,
`opencv-python-headless`, `streamlit` and `tqdm` are expected to come from the base Python install (the virtual
environment is created with `--system-site-packages`).

## Data

1. Download the RefleX dataset: the archive `reflex_img_1024_inter_nearest.zip` (1024-px images, nearest-neighbor
   downsampling) and the label files `labels_train.csv`, `labels_val.csv`, `labels_test.csv`.
2. Place everything in `data/raw/`.
3. Verify and extract the images:

```bash
python -m src.prepare_data
```

This checks the MD5 checksum of the zip and extracts it to `data/raw/reflex_img_1024_inter_nearest/`.

Each labels CSV has one row per image: an `image` column (file name without extension) and one 0/1 column per class.
Split sizes: 5048 train / 631 validation / 632 test images.

## Usage

Run every command from the project root.

### Train

```bash
# Stage 1: frozen backbone, train only the head
python -m src.train --name baseline_resnet50_frozen --amp

# Stage 2: fine-tune the whole network starting from stage 1
python -m src.train --name resnet50_finetune --unfreeze --init-from baseline_resnet50_frozen.pt \
    --lr 1e-4 --backbone-lr 1e-5 --amp
```

Options:

| Flag | Meaning |
|---|---|
| `--name` | Run name; the checkpoint is saved to `checkpoints/<name>.pt` |
| `--unfreeze` | Train the entire backbone (fine-tuning) |
| `--init-from` | Checkpoint in `checkpoints/` used as the starting point |
| `--epochs`, `--batch-size` | Defaults: 30 epochs, batch size 16 |
| `--lr`, `--backbone-lr` | Learning rate of the head / of the backbone (default head LR 3e-4) |
| `--weight-decay` | AdamW weight decay (default 1e-4) |
| `--amp` | bfloat16 autocast (faster on recent NVIDIA GPUs) |
| `--aug` | `rotate10` (default) or `dihedral` |
| `--workers`, `--seed` | DataLoader workers (default 4), random seed (default 42) |

Each run writes `reports/history_<name>.csv` and `reports/config_<name>.json` (all arguments, git commit and start
time) so that experiments stay reproducible. The example learning rates above are illustrative; check
`reports/config_<name>.json` of your own runs for the exact settings used.

### Evaluate

```bash
python -m src.evaluate --checkpoint resnet50_finetune.pt --figures --amp
```

Prints per-class AP/F1 on validation and test, then the paper-style metrics (accuracy, MCC, Jaccard index, precision,
recall, F1, AUC per class; macro precision/recall/F1/F2, mean MCC, sample-wise Jaccard and exact match ratio in
aggregate). `--figures` also exports the plots to `reports/figures/<checkpoint>/`. Pass `--amp` only if the
checkpoint was trained with `--amp`.

### Explain predictions (Grad-CAM)

```bash
python -m src.explain --checkpoint resnet50_finetune.pt --classes ice_ring loop_scattering
```

For each requested class, picks the test image of that class with the highest predicted probability and overlays the
Grad-CAM heat map of the last convolutional layer.

## Notes

- Metric definitions follow the reference paper; `AUC_bin` in the evaluation output is the AUC of the hard 0/1
  predictions (equivalent to balanced accuracy), as computed in the paper.
- For the sample-wise Jaccard index, an image with no true anomaly and none predicted counts as a perfect match.
- Notebook outputs were produced with the earlier Portuguese version of the labels; all code and figures in the
  repository now use English names.
